# JPD123 Web App

Đây là ứng dụng web tĩnh được thiết kế chuyên biệt cho việc ôn tập và thi thử môn tiếng Nhật JPD123. Ứng dụng chạy hoàn toàn ở phía client (trình duyệt), không cần máy chủ (backend) hay cơ sở dữ liệu.

## Các tính năng chính

* **Ôn tập Lý thuyết**: Tra cứu lý thuyết, từ vựng, Kanji và quy tắc học tập.
* **Làm trắc nghiệm**: Hỗ trợ chia theo từng chặng 50 câu, hoặc gộp tổng hợp toàn bộ ngân hàng câu hỏi.
* **Thi thử FE**: Mô phỏng bài thi Final Exam với thời gian đếm ngược.
* **Trò chơi hóa (Gamification)**:
  * Hệ thống tính điểm kinh nghiệm (XP) và thăng cấp (Level).
  * Kho huy hiệu thành tựu (Achievements).
  * Hiệu ứng âm thanh và hình ảnh (bắn pháo hoa, rung lắc khi làm sai).
* **Gia sư AI (Tích hợp Gemini Notebook)**: Tự động điều hướng sang Gemini Notebook cá nhân của bạn với Prompt được thiết kế chuyên sâu để giải thích ngữ pháp và từ vựng cho người "mất gốc".
* **Giao diện sáng/tối (Dark Mode)** thân thiện với mắt.

## Cách sử dụng

Ứng dụng này chỉ bao gồm HTML, CSS và JavaScript thuần. 
Bạn chỉ cần tải toàn bộ mã nguồn về, mở file `index.html` bằng bất kỳ trình duyệt nào (Chrome, Edge, Safari...) là có thể sử dụng được ngay.

## Hướng dẫn triển khai lên GitHub Pages (Miễn phí)

1. Tạo một Repository mới trên GitHub (Ví dụ: `jpd123-quiz`).
2. Tải toàn bộ thư mục này lên Repo đó.
3. Vào phần **Settings > Pages**.
4. Ở mục **Source**, chọn nhánh `main` (hoặc `master`).
5. Đợi 1-2 phút, GitHub sẽ cung cấp cho bạn một đường link chạy thực tế. Bạn có thể gửi link này cho bạn bè cùng ôn tập!
